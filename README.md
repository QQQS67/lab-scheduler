# 实验室设备预约与借用管理系统

一个从零构建的全栈项目，用于系统学习 Vue3 + TypeScript + Node.js 全栈开发，
并作为实习简历上的主力项目。

## 项目背景

解决实验室设备借用流程靠纸质登记、时段冲突靠人工协调的问题。
覆盖设备浏览、时段预约、审批流、借用归还、逾期处理的完整业务闭环。

## 技术栈

| 层 | 选型 | 说明 |
|---|---|---|
| 前端 | Vue 3 + TypeScript + Vite | 组合式 API |
| UI | Element Plus | 表格、表单、分页、日历、上传 |
| 状态管理 | Pinia | 按业务域拆分 |
| 路由 | Vue Router | 菜单与按钮级权限 |
| 后端 | Node.js + Express + TypeScript | REST API |
| 数据库 | MySQL 8.0 + Prisma | 事务、索引、乐观锁 |
| 鉴权 | JWT + RBAC | 学生 / 导师 / 管理员三角色 |

## 计划中的核心功能

- [ ] 设备列表与详情，支持分类筛选与关键字搜索
- [ ] 可视化时段预约，冲突自动拦截
- [ ] 审批流与状态机：待审批 → 已通过 → 已借出 → 已归还 / 逾期
- [ ] 菜单级与按钮级权限动态渲染
- [ ] 借用记录统计与导出

## 技术难点（面试可讲的点）

1. **并发预约冲突**：同一设备同一时段被多人预约。
   采用 MySQL 唯一索引 + 事务 + 乐观锁版本号三重保障。
2. **权限模型**：RBAC 三角色，前端路由与按钮双维度控制，后端接口二次校验。
3. **请求层封装**：Axios 拦截器统一处理 token 刷新与错误码。
